# 拼多多评论采集 · 工具中心接入版

从工具库打开，保留原来的商品选择、评论数量、页间隔、抓取最新、当前进度、商品勾选及 Excel 导出页面。原项目不修改。

此版本不使用企业钉钉登录，也不启动 6767 登录服务。后续由平台统一提供登录。拼多多账号仍需在自动打开的专用 Chrome 中正常登录，手动选择商品。

与原版的必要差异：配置和数据库放在版本目录之外；取消刷新页面时自动清空记录，仅通过原“清空所有记录”按钮删除；移除钉钉登录标签与退出链接；只统一颜色和字体，不改变页面布局。

Excel 列保持“用户名称、商品型号、评论”。点击原导出按钮会下载 Excel，并同时归档到工具中心“结果文件”。

运行要求：Node.js 22 或以上版本（支持 node:sqlite）、附带 npm、Google Chrome。首次打开自动按锁文件安装运行组件。组件在 runtime/node-envs/pdd-review/版本号，SQLite 和专用浏览器目录在 state/tools/pdd-review，导出在 outputs/pdd-review。更新代码不删除这些数据。此目录不包含账号配置、原数据库或浏览器资料。
